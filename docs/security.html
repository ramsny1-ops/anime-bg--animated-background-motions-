Security

Security model, configuration safety, and responsible vulnerability reporting.

v3.0.015 effectsVanilla JavaScriptNo runtime dependencies

Scope

anime-bg is a client-side visual library and does not require a server, account, token, external API, or network request. Security issues can still matter when code is embedded into larger applications.

Do not publish sensitive vulnerability details in a public issue before maintainers have had a reasonable chance to review them.

Configuration import

Imported configuration is parsed as JSON, constrained to known configuration keys, mapped to existing form controls, and range-clamped. It is not evaluated as JavaScript.

Reporting

Use the process described in SECURITY.md. Include affected version, browser, reproduction steps, impact, and a minimal proof of concept when appropriate.
