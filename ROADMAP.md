# Roadmap

anime-bg focuses on dependency-free browser creative coding.

## Near term

- optional spatial-grid optimization for proximity effects;
- benchmark page comparing particle counts and frame times;
- more keyboard-accessible non-pointer interaction modes;
- additional color-palette presets;
- unit tests for pure math helpers;
- high-contrast documentation screenshots.

## Future effect ideas

- flow-field particles;
- boids and flocking;
- elastic particle mesh;
- metaball-inspired canvas field;
- fireworks system;
- snow and wind field;
- magnetic field lines;
- particle text morphing;
- collision sandbox;
- procedural galaxy.

## Non-goals

anime-bg does not aim to become a large rendering engine or framework. The
project should remain easy to read, copy, customize, and learn from.
