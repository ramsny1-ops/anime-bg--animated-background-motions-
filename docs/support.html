Support

How to diagnose issues and provide useful technical information when asking for help.

v3.0.015 effectsVanilla JavaScriptNo runtime dependencies

Before asking for help

  1. Run bun run verify.
  2. Open the browser console.
  3. Try the effect with default configuration.
  4. Reduce quality and density if the issue is performance-related.
  5. Check the effect-specific README.

Useful diagnostic information

Include browser version, operating system, effect name, exported JSON configuration, console errors, and whether the issue reproduces with pointer interaction disabled.
