# Code of Conduct

## Our commitment

anime-bg is intended to be a welcoming learning and creative-coding project.
Contributors, maintainers, reviewers, and users are expected to help keep project
spaces respectful, constructive, and useful.

## Expected behavior

Good participation includes:

- discussing ideas and disagreements with technical reasoning rather than personal attacks;
- giving feedback about code, documentation, design, and behavior without insulting people;
- respecting different experience levels, languages, backgrounds, and learning styles;
- keeping issues and pull requests focused on the project;
- crediting other contributors and external ideas when appropriate;
- accepting maintainers' decisions about scope while remaining free to propose alternatives;
- helping new contributors understand the repository instead of gatekeeping knowledge.

## Unacceptable behavior

The following behavior is not welcome in project spaces:

- harassment, threats, stalking, intimidation, or targeted abuse;
- discriminatory or degrading comments;
- publishing another person's private information without permission;
- sexualized language or unwanted sexual attention;
- deliberate disruption of discussions or contribution workflows;
- spam, malicious files, intentionally unsafe code, or deceptive pull requests;
- sustained personal arguments unrelated to the technical work.

## Scope

This code of conduct applies to repository issues, pull requests, discussions,
review threads, and other spaces officially used by the anime-bg project.

## Reporting

If a project space becomes unsafe or abusive, contact the repository maintainer
privately through the contact method published on the maintainer's GitHub profile.
Do not post sensitive personal information in a public issue.

Reports should include enough context for the maintainer to understand what happened.
Maintainers should review reports fairly, preserve privacy where practical, and take
action proportionate to the situation.

## Enforcement

Possible responses include a private warning, removal of offending content,
temporary participation restrictions, rejection of a contribution, or a permanent
ban from project spaces.

## Attribution

This policy is inspired by common open-source community standards and is written
specifically for anime-bg.
