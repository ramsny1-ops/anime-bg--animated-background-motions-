Accessibility

Keep decorative animation compatible with keyboard use, readable content, and reduced-motion needs.

v3.0.015 effectsVanilla JavaScriptNo runtime dependencies

Decorative motion should stay decorative

Canvas visuals never carry required information. Interactive controls use native buttons, ranges, checkboxes, selects, and links. Keyboard shortcuts are suppressed while editing a control.

Reduced motion

@media (prefers-reduced-motion: reduce) {
  /* Lower or disable continuous animation in your production integration. */
}

Contrast

The documentation UI uses strong text contrast and reserves accent colors for state, navigation, and emphasis rather than large decorative surfaces.
