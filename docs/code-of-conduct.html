Community standards for respectful, focused, professional collaboration.

Expected behavior

Participate professionally, critique code rather than people, welcome different skill levels, and keep discussions focused on improving the project.

Unacceptable behavior

Harassment, threats, discrimination, deliberate disruption, doxxing, and other abusive behavior are not acceptable.

Enforcement

Maintainers may edit or remove contributions, comments, issues, code, or other material that violates project standards. See the full CODE_OF_CONDUCT.md for the source policy.
