Performance

Think in frame budgets

At 60 frames per second, the browser has roughly 16.7 milliseconds for the whole frame, not only the animation. The background should leave time for layout, input, application JavaScript, painting, and compositing.

Rendering quality and DPR

anime-bg clamps effective device pixel ratio and exposes a quality multiplier. This is often the fastest way to protect low-power hardware because high-DPR canvases can multiply the number of pixels dramatically.

const deviceScale = window.devicePixelRatio || 1;
dpr = clamp(deviceScale * runtime.qualityScale, 0.5, 2);

Particle density

First performance lever: reduce particle count before removing the character of an effect.

Some effects have pairwise relationships. Spider Network is the clearest example: naive proximity comparisons grow approximately with the square of particle count. Other effects scale closer to linearly.

Stable timing

const dt = clamp((time - lastTime) / 1000, 0, 0.033);
lastTime = time;

Clamping delta time avoids giant simulation jumps when a tab resumes or the browser stalls briefly.
