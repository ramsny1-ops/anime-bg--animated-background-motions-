A background effects system, not a snippet dump

anime-bg packages fifteen independent Canvas scenes with a consistent professional control layer. Every effect can run alone, be copied into another project, or be used as a reference implementation for Canvas animation, pointer physics, particles, trails, procedural drawing, and performance tuning.

Shared quality philosophy
Flexible by design. Each effect supports live palette changes, speed, density, intensity, pointer interaction, quality scaling, JSON import and export, snapshots, local presets, pause and resume, and diagnostics.

Quick start

Extract or clone

cd anime-bg

Verify the repository

bun run verify

Serve static files

bun run serve

Open the gallery

Use the address printed by the local static server and choose any effect.

Project standards

Copyable

An effect folder remains useful without a framework, bundler, or external package.

Inspectable

JavaScript uses explicit classes, functions, named configuration, and bounded animation logic.

Responsive

Canvas sizing follows its container and clamps rendering resolution.

Professional workflow

Security policy, code of conduct, contribution guide, changelog, roadmap, issue templates, and verification are included.
