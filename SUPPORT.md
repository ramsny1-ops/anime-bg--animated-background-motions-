# Support

anime-bg is designed to be understandable without a support service.

## Start here

- Read the root `README.md` for project setup.
- Read the README inside the effect you are using.
- See `docs/CUSTOMIZATION.md` for configuration patterns.
- See `docs/EMBEDDING.md` for adding effects to another website.
- See `docs/PERFORMANCE.md` if animation is slow.
- Run `bun run verify` before reporting a repository problem.

## Bug reports

Use the bug-report issue template and include the effect name, browser, viewport,
steps to reproduce, and expected behavior.

## Questions

For a usage question, include a minimal code sample showing how you embedded or
modified the effect. That makes it much easier for another contributor to reproduce
the problem.

## Security issues

Do not use a public support issue for a vulnerability. Follow `SECURITY.md`.
