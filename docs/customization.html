Customize without editing code

Every effect exposes a live studio with simulation controls, effect-specific parameters, palette inputs, rendering quality, playback, preset persistence, configuration import and export, snapshots, and diagnostics.

Recommended workflow: tune visually first, export JSON when the scene feels right, then copy those values into the effect defaults for production.

Change production defaults

const DEFAULTS = Object.freeze({
  particleCount: 160,
  speed: 0.9,
  particleSize: 2,
  intensity: 1,
  particleColor: "#f7f8ff",
  accentColor: "#8c73ff",
  backgroundColor: "#08090c",
  pointerEnabled: true
});

Use design tokens

Keep visual effects subordinate to content. The project UI itself uses mostly black, white, restrained purple, and a small green signal color. Your embedded effect can use any six-digit hexadecimal palette.

TokenRoleAdvice
particleColorPrimary geometryUsually highest contrast
accentColorSecondary energy, links, glowUse brand color carefully
backgroundColorCanvas clear colorMatch the surrounding section

Flexible container embedding

.anime-background {
  position: relative;
  min-height: 420px;
  overflow: hidden;
}
.anime-background canvas {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
}

The stage also supports data-embed="true" to hide its laboratory controls when you are demonstrating the complete page locally.

Portable JSON configuration

{
  "project": "anime-bg",
  "effect": "11-aura-energy-field",
  "schemaVersion": 1,
  "config": {
    "particleCount": 180,
    "speed": 0.8,
    "accentColor": "#8c73ff"
  }
}

Imported values are validated against controls and clamped to their supported input ranges.
