# Changelog

## 3.0.0 - 2026-08-31

### Added

- Renamed project to anime-bg.
- Expanded the library from 10 to 15 effects.
- Added Aura Energy Field, Sakura Drift, Speed-Line Burst, Spirit Flame, and Celestial Orbit.
- Added enterprise-style HTML documentation for project README, customization, performance, contributing, architecture, accessibility, security, support, roadmap, and code of conduct.
- Added searchable and filterable 15-effect gallery.
- Added root customization and performance entry documents.

All notable project changes are documented here.

The project follows a simple semantic-versioning approach for public releases.
